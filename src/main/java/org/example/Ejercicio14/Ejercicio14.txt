Ejercicio 14 - Tablas Hash

Datos del problema

- Claves (en orden de insercion): 45, 12, 37, 82, 29, 54, 31, 76, 18, 93, 11, 68
- Estrategias:
  - Sondeo lineal
  - Sondeo cuadratico
  - Encadenamiento separado

1) Tamanio de tabla y justificacion

Se usa m = 13.

Justificacion:
- Hay 12 claves.
- 13 es primo y cercano a 12.
- Permite comparar las 3 estrategias con la misma tabla y sin redimensionar.

2) Funcion hash

Se usa:
h(k) = k mod 13

Es una funcion simple y adecuada para claves enteras.

7) Comparacion y conclusion

Para este conjunto de claves, encadenamiento separado fue la estrategia que mejor funciono:
- Menor cantidad de colisiones.
- Menor promedio de comparaciones en busquedas exitosas.
- Menor promedio de comparaciones en busquedas no exitosas.

Entre las estrategias de direccion abierta, el sondeo lineal rindio mejor que el cuadratico para este caso puntual.
