# Ejercicio 7

Se implementa:

1. Carga de palabras en:
   - `LinkedList`
   - `ArrayList`
   - `SimpleTrie`
   - `HashMap`
   - `TreeMap`
2. Busqueda de claves cargadas en `listado-general-palabrasBuscar.txt`, ejecutada 20 veces.
3. Consolidacion de resultados de tiempo y memoria (Parte 4).
4. Medicion de `predecir` para prefijo `cas` en:
   - `Trie`
   - `LinkedList`
   - `HashMap`
   con 20 mediciones por alternativa (Parte 5).

## Clase principal

`org.example.Ejercicio7.Ejercicio7Main`

## Archivos de entrada

Por defecto se buscan en este orden:

1. `src/main/resources/Ejercicio7/`
2. `ut03/`
3. Directorio actual

Nombres esperados:

- `listado-general-desordenado.txt`
- `listado-general-palabrasBuscar.txt`

## Salida

Se generan en `salidas/Ejercicio7/`:

- `resultados_busqueda.csv`
- `resultados_predecir.csv`
- `resultados_consolidados.md`
